# Methodology

> Scaffold only. Full methodology to be documented as experiments are completed.

## Research Question

How do social-media-style transformations such as JPEG compression, resizing,
recompression, and combinations of transformations affect AI-generated image
detection performance, and can transformation-aware training improve detector
robustness?

## Pipeline (per AGENTS.md)

Dataset -> Dataset Audit -> Bias Analysis -> Controlled Dataset ->
Train / Validation / Test Split -> Clean Baseline Training ->
Clean Test Evaluation -> Transformation Experiments -> Robustness Analysis ->
Transformation-Aware Training -> Robust Model Evaluation ->
Standard vs Robust Comparison -> Error Analysis -> Streamlit Demonstration
